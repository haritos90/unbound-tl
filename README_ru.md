# unbound-tl — проект перевода ROM-хака Pokemon Unbound 2.1.1.1, который выпускается как патч для ROM Unbound

[English](README.md) | **Русский**

> [!IMPORTANT]
> Это неофициальный проект. Skeli и команда Pokemon Unbound не поддерживают его и не имеют к нему отношения.
>
> Применение патча к ROM может повлиять на игровой опыт.

Что меняет перевод:

- тексты игры и указатели на них;
- глифы шрифтов и картинки с текстом;
- клавиатуры для ввода имён и чата, а также порядок слов в чате — по алфавиту языка;
- игровой процесс не меняется: сюжет, бои, файлы сохранений и игра по связи работают как в оригинале;
- код игры не меняется, за двумя исключениями:
  - В языках с метрической системой рост и вес на странице Покедекса показываются в метрах и килограммах. Для этого заменены две процедуры отрисовки; сами значения, которые используют такие приёмы, как Подсечка, остаются прежними.
  - Экран Декснава рисует имена шрифтом из картинок. Подбор картинки для буквы заменён, чтобы на экране можно было показывать буквы языка.

Чтобы установить выпущенный перевод, воспользуйтесь [патчером](https://haritos90.github.io/gen3tl/patch) на сайте gen3tl. Оригинальный ROM здесь не распространяется.

## Помочь с переводом

Править перевод и отправлять изменения можно в [редакторе перевода](https://haritos90.github.io/gen3tl/editor). Он работает в браузере, и вся работа хранится на вашем компьютере, пока вы её не отправите. Порядок действий описан в [CONTRIBUTING.md](CONTRIBUTING.md).

## Добавить язык

Создайте задачу в этом репозитории и укажите язык либо откройте пул-реквест, который добавляет папку языка ([CONTRIBUTING.md](CONTRIBUTING.md#add-a-language)).

## Как хранятся языки

У каждого языка своя папка `translation/<code>/`; её имя — код языка.

| Путь в папке | Содержимое |
| --- | --- |
| `po/` | переведённые тексты в файлах gettext PO, сгруппированных по частям игры |
| `pokedex-labels.po` | подписи страниц Покедекса |
| `glossary.tsv` | термины игры и их переводы |
| `policy.toml` | настройки языка, например клавиатура ввода имени |
| `release.toml` | состояние выпуска языка |
| `graphics/` | переведённые картинки |

- Запись PO содержит ключ текста и его перевод. Текст на языке оригинала в репозитории не хранится: редактор читает его из ROM.
- Новый язык начинается с файлов PO, `policy.toml` и `release.toml`; остальные файлы появляются по мере перевода.

## Добавить игру

Этот проект посвящён одной игре. Чтобы добавить в gen3tl другую игру, создайте задачу в [репозитории gen3tl](https://github.com/haritos90/gen3tl/issues).
